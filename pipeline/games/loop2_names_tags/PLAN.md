# Loop 2: Новые названия + Теги для игр

## Задача
Переписать названия (G) и заполнить теги (M) для ключей игр и DLC.

## Названия

### Формулы
- **Ключ игры:** `Ключ активации [Название игры] для Steam | [Регион] | Цифровой код`
- **DLC:** `DLC [Название DLC] для [Игра] | Steam | [Регион] | Цифровой код`

### Ротация
- **Тип:** Ключ активации / Цифровой ключ / Электронный ключ
- **Суффикс:** Цифровой код / Электронный код / Официальный ключ

### КРИТИЧНО
- НЕ писать "подарок Steam", "Steam Gift" — это ключ, не подарок
- Для DLC — указать базовую игру если понятно из названия

## Теги
- До 10 штук, каждый до 20 символов
- Примеры: ключ Steam, игра, PC игра, цифровой код, [название игры], [жанр]

## Источник данных
- Читает: source.jsonl
- Пишет: рабочий jsonl (колонки G, M)

## Обработка
- По одному товару
- ~730 товаров

## Валидация
- Длина 30-150 символов
- Не содержит "подарок Steam" / "Steam Gift"
- Название игры из старого названия сохранено
