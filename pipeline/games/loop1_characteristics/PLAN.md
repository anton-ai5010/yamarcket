# Loop 1: Заполнение и проверка 18 колонок (AN-BH) для игр

## Задача
Заполнить/проверить характеристики для ключей игр и DLC. Обработка по одному товару.

## Отличия от карт

| Колонка | Значение для игр |
|---------|-----------------|
| K (Бренд) | Без бренда (для игр/DLC) |
| AN (Применение) | сервис активации |
| AO (Назначение) | игры |
| AP (Название сервиса) | Название игры (Dead Island, SCUM и т.д.) |
| AR (Платформа) | ПК (для Steam), зависит от магазина |
| AS (ОС) | Windows (для Steam) |
| AT (Сервис активации) | Steam / другой магазин |
| AU (Номинал) | Пусто (у игр нет номинала) |
| AV (Продолжительность) | 99 лет |
| AW (Территория) | Из названия (GL, CIS, EU и т.д.) |
| BA (Возрастное ограничение) | 17+ или 18+ |
| BC (Доп. информация) | "Для аккаунтов всех стран" / "не подходит для РФ, СНГ и КНР" |

## Источник данных
- Читает: source.jsonl (старые названия + описания)
- Пишет: рабочий jsonl (колонки K, AN-BH)
- Шаблон: rules_games.md

## Обработка
- По одному товару, одна итерация = один товар
- ~730 товаров

## Валидация
- AN = "сервис активации"
- AT не пустой
- AW не пустая
- Бренд K = "Без бренда" для игр/DLC
