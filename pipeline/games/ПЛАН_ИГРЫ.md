# Pipeline: Игры и DLC

~730 товаров, обработка по одному.

## Данные

### Источники
Те же файлы что и для карт:
- **Источник истины:** `istina/истина_оригинал_названия_и_описания.xlsx` → csv
- **Рабочая копия:** `istina/Онлайн-подписки и карты оплаты_истина_названия_описания.xlsx` → csv

### Особенности
- Товары **без группы** — каждый обрабатывается отдельно
- Ключ активации ≠ подарок Steam (важно для описаний!)
- DLC и сами игры — всегда без группы
- Пополнение счёта игры (PUBG UC, Valorant VP и т.д.) — **уходят в pipeline/cards/** как группы

## Циклы Ralph Loop

### Loop 0: Проверка классификации
- **Задача:** Убедиться что все ~730 товаров правильно определены как игры/DLC
- **Проверить:** не попало ли сюда пополнение счёта (должно быть в cards/)
- **Проверить:** правильно ли отсутствует группа

### Loop 1: Заполнение/проверка 18 колонок (AN-BH)
- **Аналогично cards**, но свои правила:
  - AN (Применение): `сервис активации`
  - AO (Назначение): `игры`
  - AT (Сервис активации): `Steam` / другой магазин
  - BA (Возрастное ограничение): `17+` или `18+`
- **По одному товару**, не по группам

### Loop 2: Новые названия (G)
- **Формула для игр:** `Ключ активации [Название игры] для Steam | [Регион] | Цифровой код`
- **Формула для DLC:** `DLC [Название DLC] для [Игра] | Steam | [Регион] | Цифровой код`
- **Важно:** НЕ писать "подарок Steam", "Steam Gift" — это ключ, не подарок

### Loop 3: Новые описания (J)
- **Поиск референсов:** Playwright → Маркет (поиск по названию игры)
- **КРИТИЧНО:** Различать "ключ активации" и "подарок Steam" — разные товары!
  - Наш товар = ключ, который активируется в Steam
  - НЕ наш товар = подарок через Steam, отправляется другу
- **Если Claude находит карточку "подарка"** — НЕ брать оттуда текст
- **HTML-структура:** h2 + что это за игра + что получите + как активировать + системные требования (если есть) + важно

### Loop 4: Добавить инструкцию в описание (J)
- **Инструкция для Steam-ключей** стандартная:
  1. Откройте Steam и войдите в аккаунт
  2. Нажмите "Игры" → "Активировать продукт в Steam"
  3. Введите ключ
  4. Игра появится в библиотеке
- **Для других платформ** — искать на pyyplbot.com

### Loop 5: Главная картинка (AI + Pillow)
- **Специфика:** для игр главная картинка = обложка игры или стилизованная карточка
- **Делается в pipeline/card_images/**

### Loop 6: Шаблонные картинки (Pillow)
- Те же шаблоны что и для карт, но адаптированные
- **Делается в pipeline/card_images/**
