# Loop 4: Добавить инструкцию активации для игр

## Задача
Дописать инструкцию по активации в конец описания (J).

## Стандартная инструкция для Steam-ключей
```html
<p><b>Как активировать:</b></p>
<ol>
<li>Откройте приложение Steam и войдите в аккаунт</li>
<li>Нажмите «Игры» в верхнем меню → «Активировать продукт в Steam»</li>
<li>Примите условия и введите ключ активации</li>
<li>Игра появится в вашей библиотеке Steam</li>
</ol>
```
