## Циклы Ralph Loop

### Loop 0: Проверка/исправление групп (F)
- **Задача:** Перепроверить все группы, исправить ошибки скрипта
- **Логика:** Пополнение счёта игры → группа по номиналам/странам. Карты/ваучеры → группа по бренду+валюте+территории
- **После:** Загрузить на Маркет → выгрузить обратно для фиксации

### Loop 1: Заполнение/проверка 18 колонок (AN-BH)
- **Вход:** csv-источник (старые название + описание)
- **Пишет:** рабочий csv
- **Шаблон:** доработанный РЕШЕНИЯ_ПО_СТОЛБЦАМ.md
- **Логика:** По группам, внутри группы всё одинаковое кроме номинала (AU)
- **Дозаполнить:** AT (сервис активации, 55% пустых), AU (номинал, 26% пустых)
- **Очистить:** Бренды с `|` → правильные (brand_mapping)

### Loop 2: Новые названия (G)
- **Вход:** csv-источник (старые название + описание)
- **Пишет:** рабочий csv
- **Шаблон:** файл с правилами названий + примеры
- **Формула:** Тип + Бренд/Сервис + Номинал + Валюта | Регион | Суффикс
- **Ротация:** начало, валюта, суффикс — разные внутри группы
- **Референс:** pyyplbot + Маркет (карточки с продажами)

### Loop 3: Новые описания (J)
- **Вход:** csv-источник (старые название + описание)
- **Пишет:** рабочий csv
- **Переписываем ВСЕ** описания (и HTML, и plain text)
- **Поиск референсов:** Playwright → pyyplbot.com, витрина на Маркете, поиск по Маркету
- **Не копируем** — переписываем своими словами, смысл товара не меняется
- **HTML-структура:** h2 + что это + что получите + для чего + важно
- **1000-2000 символов**

### Loop 4: Добавить инструкцию в описание (J)
- **Вход:** рабочий csv (новое описание из Loop 3)
- **Пишет:** рабочий csv (дописывает в конец описания)
- **Поиск:** Playwright → pyyplbot.com, при необходимости Маркет
- **Формат:** <p><b>Как активировать:</b></p><ol><li>шаг 1</li>...</ol>

### Loop 5: Главная картинка (AI + Pillow)
- **AI-генерация:** изображение карты в фирменных цветах бренда
- **Pillow:** текст (название, номинал, флаг, регион), фон магазина
- **Формат:** 1080x1440 (3:4)
- **Делается в pipeline/card_images/**

### Loop 6: Шаблонные картинки (Pillow)
- **8 картинок на товар**, фон единый (стиль магазина)
- Картинки 2,6,7,8 — одинаковые для всех (меняется только регион внизу)
- Картинки 3-5 — зависят от бренда (инструкции активации)
- **Делается в pipeline/card_images/**
