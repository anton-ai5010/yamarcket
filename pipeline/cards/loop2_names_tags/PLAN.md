# Loop 2: Новые названия + Теги

## Задача
Переписать названия (G) и заполнить теги (M) для всех товаров. Источник истины — старое название + старое описание.

## Названия

### Формула
`Тип + Бренд/Сервис + Номинал + Валюта | Регион | Суффикс`

### Ротация внутри группы
- **Тип:** Подарочная карта / Карта пополнения / Пополнение / Подарочный сертификат / Карта оплаты
- **Валюта:** Полное название (Долларов) / Код (USD) / Символ ($)
- **Суффикс:** Официальный цифровой код / Цифровой ключ активации / Электронный код

### Правила
- Оптимум 50-60 символов, максимум 150
- Смысл товара НЕ меняется (номинал, регион, валюта — как в старом названии)
- Запрещено: дублирование слов, реклама, CAPS, спецсимволы

### Референсы
- pyyplbot.com + витрина на Маркете (карточки с продажами)
- Playwright для поиска

## Теги

- До 10 штук, каждый до 20 символов
- Примеры: подарочная карта, gift card, цифровой код, подарок, [бренд], [сервис], пополнение, ваучер
- Варьировать внутри группы для охвата разных поисковых запросов

## Источник данных
- Читает: source.jsonl (старые названия + описания из истины)
- Пишет: рабочий jsonl (колонки G, M)
- Шаблон: name_rules.md (правила + примеры)

## Обработка
- По группам, одна группа = одна итерация
- ~350 групп

## Валидация
- Длина названия: 30-150 символов
- Нет дублирования слов
- Теги не пустые, каждый ≤20 символов
- Номинал из старого названия сохранён в новом
