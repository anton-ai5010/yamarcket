# Loop 0: Проверка и исправление групп

## Задача
Перепроверить все группы товаров (колонка F) на корректность. Скрипт `group_variants.py` мог ошибиться.

## Что проверяем
1. **Правильность объединения** — нет ли в одной группе товаров из разных регионов/валют
2. **Пропущенные товары** — не осталось ли без группы товар, который должен быть в группе
3. **Лишние товары** — не попало ли DLC или игра в группу карт

## Правила группировки
- Карты/ваучеры → группа по: бренд + валюта + территория
- Пополнение счёта игры (PUBG UC, Valorant VP) → группа по номиналам/странам
- DLC и ключи игр → БЕЗ группы, уходят в pipeline/games/
- Подписки (PS Plus, Xbox Game Pass) → группа по: сервис + территория + тип подписки

## Источник данных
- Читает: `istina/` → source.jsonl (старые названия + описания)
- Пишет: рабочий jsonl (колонка F)
