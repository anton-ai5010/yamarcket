# Loop 1: Заполнение и проверка 18 колонок (AN-BH)

## Задача
Заполнить/проверить характеристики товаров. Источник истины — старое название + старое описание.

## Колонки

| Колонка | Поле | Логика заполнения |
|---------|------|-------------------|
| K | Бренд | Очистить `\|` суффиксы (Apple Gift Card \| AE → Apple) |
| AN | Применение | По типу товара: пополнение счета / оплата подписки / оплата игровой валюты |
| AO | Назначение | По бренду: игры / музыка / покупки и т.д. |
| AP | Название сервиса | По бренду: PlayStation Store / Steam / iTunes и т.д. |
| AQ | Вид поставки | Всегда: электронный ключ |
| AR | Платформа | По бренду: PlayStation 4,PlayStation 5 / ПК / мобильное устройство |
| AS | Совместимость с ОС | По бренду: Windows / Android,iOS / macOS |
| AT | Сервис активации | По бренду: PlayStation Store / Steam / Xbox Store (55% пустых!) |
| AU | Номинал карты | Парсинг из названия (26% пустых!) |
| AV | Продолжительность подписки | 99 лет / реальный срок для подписок |
| AW | Территория активации | Из названия/описания |
| AX | Бонусы | Пусто |
| AY | Жанр игры | Пусто |
| AZ | Кол-во аккаунтов | Всегда: 1 |
| BA | Возрастное ограничение | По бренду: 0+ / 12+ / 13+ / 16+ / 18+ |
| BB | Инструкция по активации | Всегда: Инструкция в описании |
| BC | Дополнительная информация | "Только для [страна] аккаунтов" |
| BD | Активация после покупки | Всегда: бессрочно |
| BE | Кол-во упаковок | Всегда: 1 |
| BF | Территория использования | Совпадает с AW |

## Источник данных
- Читает: source.jsonl (старые названия + описания из истины)
- Пишет: рабочий jsonl (колонки K, AN-BH)
- Шаблон правил: rules.md (компактная версия РЕШЕНИЯ_ПО_СТОЛБЦАМ)

## Обработка
- По группам (внутри группы всё одинаковое кроме AU номинал)
- Одна группа = одна итерация Ralph Loop
- ~350 групп карт

## Валидация (после каждой группы)
- Скрипт `validate.py` проверяет:
  - AN, AO, AP, AQ, AR, AS, AT — не пустые
  - AU — число (если gift card/wallet)
  - AW — не пустая
  - BA — из допустимых значений
  - Бренд K — без `|`
- Ошибки → errors.json, группа помечается как "retry"
