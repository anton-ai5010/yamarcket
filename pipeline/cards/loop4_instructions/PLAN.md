# Loop 4: Добавить инструкцию активации в описание

## Задача
Дописать инструкцию по активации в конец описания (J). Описание из Loop 3 уже готово, сюда добавляется блок с пошаговой инструкцией.

## Формат
Дописывается в конец существующего описания:
```html
<p><b>Как активировать:</b></p>
<ol>
<li>Шаг 1</li>
<li>Шаг 2</li>
<li>Шаг 3</li>
<li>Шаг 4</li>
</ol>
```

## Поиск инструкций (Playwright)
1. **pyyplbot.com** — основной источник
2. **Маркет** — при необходимости
3. Инструкция одинаковая для всех товаров одного бренда/сервиса
4. Переписать своими словами

## Оптимизация
- Инструкция зависит от бренда, не от товара
- ~50 уникальных брендов → ~50 инструкций
- Можно собрать все инструкции заранее в файл, Ralph Loop только подставляет
- Это сильно экономит Playwright-запросы

## Источник данных
- Читает: рабочий jsonl (описание из Loop 3)
- Пишет: рабочий jsonl (дописывает в колонку J)
- Опционально: файл с готовыми инструкциями по брендам

## Обработка
- По группам, одна группа = одна итерация
- Внутри группы инструкция одинаковая (один бренд)
- ~350 групп

## Валидация
- Описание содержит блок "Как активировать"
- Есть <ol> с минимум 3 шагами
- Общая длина описания не превышает 6000 символов
