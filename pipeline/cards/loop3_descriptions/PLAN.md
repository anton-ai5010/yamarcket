# Loop 3: Новые описания

## Задача
Переписать ВСЕ описания (J) — продающие, HTML, 1000-2000 символов. Источник истины — старое название + старое описание.

## Принципы
- Смысл товара НЕ меняется
- Не копируем конкурентов — переписываем своими словами
- Описания внутри группы РАЗНЫЕ (разные формулировки, разные ключевые слова → больше охват поисковых запросов)
- Каждое описание уникальное для конкретного товара (включая номинал в тексте)

## HTML-структура
```html
<h2>Заголовок — тип + бренд + номинал + регион</h2>
<p>1-2 предложения: что это, зачем нужно</p>
<p><b>Что вы получите:</b></p>
<ul><li>...</li></ul>
<p><b>Для чего можно использовать:</b></p>
<ul><li>...</li></ul>
<p><b>Важно:</b></p>
<ul><li>Регион: ...</li><li>Срок действия: бессрочно</li></ul>
```

## Запрещено в описании
- Реклама, цены, ссылки, эмодзи
- Упоминание маркетплейсов
- Копирование конкурентов (алгоритмы Маркета распознают)

## Поиск референсов (Playwright)
1. **pyyplbot.com/gift-cards/** — основной источник
2. **Витрина ПиплБот на Маркете** (business ID 84407134)
3. **Поиск по всему Маркету** — если на pyyplbot нет
4. Приоритет: карточки с продажами
5. При капче — пользователь решает вручную

## Источник данных
- Читает: source.jsonl (старые названия + описания из истины)
- Пишет: рабочий jsonl (колонка J)

## Обработка
- По группам, одна группа = одна итерация
- НО описание уникальное для каждого товара (не одно на группу)
- ~350 групп

## Валидация
- Длина описания: 500-6000 символов
- Содержит HTML-теги (h2, p, ul, li)
- Номинал товара упомянут в тексте
- Нет запрещённых слов (реклама, маркетплейсы)
