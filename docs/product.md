# Product Context

## Цель проекта

Поднять качество карточек цифровых товаров (подарочные карты, ваучеры, пополнения, подписки) на Яндекс Маркете с 12 до 81+ баллов. Это увеличит индекс видимости (сейчас ~23%) и продажи.

## Users

Личный инструмент продавца (магазин КодХаб) для управления ~3334 карточками на маркетплейсе.

## Success Metrics

- Качество карточек: 81+ баллов (сейчас 12)
- Индекс видимости: 80%+ (сейчас ~23%)
- Все карточки с изображениями, корректными названиями, описаниями и характеристиками

## Как создаются НАЗВАНИЯ (Названия товаров)

### Формула

```
Тип товара + Бренд + [Подтип/Номинал] + [Регион] + Ключевые слова
```

### Длина

- Минимум: 40 символов
- Оптимум: 60–120 символов (Яндекс даёт до 150)
- Цель — вписаться в 60–100 символов

### Типы товаров (первое слово/словосочетание)

| Тип | Когда использовать |
|-----|-------------------|
| `Подарочная карта` | Карты с номиналом (Apple Gift Card, Steam, Google Play, PlayStation Store) |

## Как создаются ОПИСАНИЯ (Описание товара)

### Формат

Строго HTML с тегами: `<h2>`, `<p>`, `<b>`, `<ul>/<li>`, `<ol>/<li>`, `<br>`

### Длина

- Минимум: 500 символов (иначе Маркет снижает балл)
- Оптимум: 1000–2000 символов
- Максимум: 6000 символов

### Структура описания

```html
<h2>[Что это — 5-8 слов]</h2>

<p>[Что даёт продукт — 2-3 предложения о пользе и назначении]</p>

<p><b>Что вы получите:</b></p>
<ul>
<li>[Конкретный benefit 1]</li>
<li>[Конкретный benefit 2]</li>
<li>[3-5 пунктов]</li>
</ul>

<p><b>Как использовать:</b></p>
<ol>
<li>[Шаг 1 — общий]</li>
<li>[Шаг 2 — общий]</li>
</ol>

<h2>Как активировать</h2>
<p><b>Способ 1 — [платформа/метод]:</b></p>
<ol>
<li>[Конкретный шаг]</li>
```

## Как заполняются ХАРАКТЕРИСТИКИ

Категория: `досуг и развлечения / онлайн-подписки и карты оплаты`

### Ключевые поля

| Поле | Значение | Примеры |
|------|---------|---------|
| Название сервиса | Точное имя платформы | `Steam`, `PlayStation Store`, `Xbox Store`, `Nintendo eShop` |
| Платформа | Устройство/ОС | `PC`, `PS4`, `PS5`, `PS4/PS5`, `Xbox One`, `Xbox Series X/S`, `iOS`, `Android`, `PC/Mac`, `Мультиплатформа` |
| Номинал карты (AU) | Сумма с символом | `5 USD`, `10 EUR`, `£25`, `100 SAR`, `50 AED` |
| Продолжительность подписки (AV) | Только для подписок | `1 месяц`, `3 месяца`, `6 месяцев`, `12 месяцев` |
| Территория активации (AR) | Страна/регион | `США`, `Германия`, `Турция`, `ОАЭ`, `Весь мир` |
| Территория использования | Как правило = Территория активации | `США`, `Европа`, `Весь мир` |
| Назначение | Тип использования | `игры`, `пополнение счёта`, `подписка`, `мобильная связь`, `потоковое видео` |
| Цифровой товар (AL) | Всегда "Да" | `Да` |

### Поле AU (Номинал) — для карт оплаты

- Подарочные карты Steam: `$5 USD`, `$20 USD` (символ $ перед суммой)
- PlayStation Store EUR: `€5`, `€20`
- PlayStation Store GBP: `£10`, `£35`
- Apple Gift Card: `$25 USD`, `100 AED`
- Для подписок AU = пусто (подписки не имеют номинала)

### Поле AV (Продолжительность) — только для подписок

- PS Plus Essential/Extra/Deluxe: `1 месяц`, `3 месяца`, `12 месяцев`
- Xbox Game Pass Ultimate: `1 месяц`, `3 месяца`
- Spotify Premium: `1 месяц`, `3 месяца`, `6 месяцев`, `12 месяцев`
- Nintendo Switch Online: `1 месяц`, `3 месяца`, `12 месяцев`
- Для подарочных карт AV = пусто (или "99 лет" — НЕ РЕКОМЕНДУЕТСЯ, вызывает ошибки)

### КРИТИЧЕСКИ ВАЖНО: Подписки vs Карты оплаты

Подписки и карты оплаты нельзя смешивать в одном xlsx-файле если у них одно "Название группы вариантов".

**Почему:** Яндекс Маркет требует единый признак-отличие для всей группы вариантов. Подписки различаются по AV (длительность), карты — по AU (номинал). Если смешать — Маркет выдаёт ошибку "несовместимые признаки".

**Решение:** два отдельных xlsx-файла:
- `2_subscriptions.xlsx` — только реальные подписки (AV заполнен, AU пусто)
- `3.xlsx` — карты оплаты/пополнения (AU заполнен, AV пусто)

**Определение подписки:** AU пуст, AV содержит реальный срок (1/3/6/12 мес).

## Варианты товаров (группировка)

Товары объединяются в группы по полю "Название группы вариантов" (колонка AP).

Пример группы PlayStation Store USA:
- GFT164 — $10 USD (AU = $10)
- GFT165 — $20 USD (AU = $20)
- GFT167 — $25 USD (AU = $25)

Все они в одной группе вариантов. Покупатель видит одну карточку с выбором номинала.

**Признаки отличия (distinguishing marks):**
- `AU` = Номинал карты (для подарочных карт)
- `AV` = Продолжительность подписки (для подписок)
- `AR` = Территория активации (если нужно разграничить регионы)
- `AP` = Платформа (если нужно разграничить платформы)

## Изображения (Image Pipeline)

### Форматы и размеры

- Основные карточки: PNG, 1080×1440 px (соотношение 3:4)
- Рендер: 2160×2880 → масштабирование с LANCZOS anti-aliasing до 1080×1440
- Универсальные карточки: 1080×1440 PNG (50 вариантов каждой с пиксельным сдвигом)
- Инструкционные изображения: PNG, в S3 как `instructions_v2/`

### Именование файлов

Главные карточки: `{SKU}_{country_transliterated}.png`

Примеры транслитерации стран:
- США → `ssha`
- Германия → `germaniya`
- Великобритания → `velikobritaniya`
- Турция → `turtsiya`
- ОАЭ → `oae`
- Саудовская Аравия → `saudovskaya_araviya`
- Австралия → `avstraliya`
- Нидерланды → `niderlandy`
- Финляндия → `finlyandiya`
- Польша → `polsha`
- Аргентина → `argentina`
- Бразилия → `braziliya`
- Гонконг → `gonkong`

### Расположение в S3

```
https://storage.yandexcloud.net/yamarcket/main_cards/{brand}/{SKU}_{country}.png
https://storage.yandexcloud.net/yamarcket/universal/{card_name}_v{N:02d}.png
https://storage.yandexcloud.net/yamarcket/instructions_v2/instr_{service}.png
```

### 4 универсальные карточки (50 вариантов каждой)

1. `email_example_card` — пример письма с кодом активации (синий стиль)
2. `delivery_card` — как доставляется товар
3. `feedback_card` — просьба оставить отзыв
4. `support_card` — контакты поддержки

Варианты созданы сдвигом нижней части (логотип + подпись) на 1-7 пикселей по x/y:
- Сетка: 10 шагов по x (от -4 до +5) × 5 шагов по y (от -2 до +2) = 50 вариантов
- Цель: обход детектора дублей Яндекс Маркета

### Порядок изображений в карточке

1. Главная карточка бренда (из `main_cards/`)
2. email_example_card variant N
3. delivery_card variant N
4. feedback_card variant N
5. support_card variant N
6. Инструкционное изображение для сервиса (из `instructions_v2/`)

## Workflow загрузки на Яндекс Маркет

### Стандартный цикл обновления

1. Внести правки в JSON: `new table/Онлайн-подписки и карты оплаты_истина_с_характеристиками.json`
2. Запустить: `python pipeline/scripts/sync_json_to_xlsx.py`
   - Создаёт `new table/2_updated.xlsx`
3. Загрузить xlsx в Личный Кабинет Яндекс Маркета → Товары → Загрузить прайс-лист

### Загрузка изображений

1. Сгенерировать PNG через `pipeline/images/generate_cards.py`
2. Запустить `push_main_cards.py` — конвертирует PNG→JPG, обновляет JSON
3. Запустить `convert_to_png_and_upload.py` — загружает PNG в YC Storage, обновляет URL
4. (Опционально) `generate_card_variants.py` — обновить 50 вариантов универсальных карточек
5. Запустить `sync_json_to_xlsx.py` для финального xlsx

### Отдельные файлы для загрузки

- `2_subscriptions.xlsx` — загружать отдельно (только 56 подписок)
- `3.xlsx` — загружать отдельно (только карты оплаты с номиналами)

## Важные нюансы и решённые проблемы

### Battle.net (Battlenet)
Официальное название сервиса — Battle.net, но Яндекс Маркет не принимает точку в бренде. Решение: использовать `Battlenet` как название бренда в данных.

### Bigo Live
Продукт Bigo Live — мобильная валюта для стриминга. Бренд стандартизирован: `Bigo Live`.

### Дубли подписок
Если в одном xlsx подписки (AV) и карты (AU) объединены в группу вариантов, Маркет выдаёт ошибку несовместимых признаков. Решение: `2_subscriptions.xlsx` содержит только строки с реальным AV (1/3/6/12 мес).

### Детектор дублей изображений
Яндекс Маркет блокирует одинаковые изображения у разных карточек. Решение: 50 вариантов с пиксельным сдвигом позволяют использовать одни и те же базовые карточки.
