# Brainstorm: итоги обсуждения (21.03.2026)

## Решённые вопросы

### Архитектура
- **Два потока обработки:** карты/подписки (~2600, по группам) и игры/DLC (~730, по одному)
- **6+ Ralph Loop на поток**, каждый делает одну задачу
- **Формат данных:** xlsx → csv (один раз), работа в csv, csv → xlsx в конце
- **Несколько csv файлов** по задачам (source, characteristics, names, descriptions, images)
- **Progress.json** — файл-очередь для Ralph Loop
- **Промпты на английском**, данные на русском
- **Жёсткие ограничения** на чтение файлов в промпте

### Два файла
- `истина_оригинал_названия_и_описания.xlsx` — только чтение, источник истины (тоже в csv)
- `Онлайн-подписки и карты оплаты_истина_названия_описания.xlsx` — рабочая копия
- Формат рабочей копии не меняем (ни колонок, ни строк)

### Порядок циклов (Цепочка А — карты/подписки)
1. **Loop 0:** Проверка/исправление групп (F)
   - Загрузка на Маркет → выгрузка обратно для фиксации
2. **Loop 1:** Заполнение 18 колонок (AN-BH) из старых названий/описаний
3. **Loop 2:** Новые названия (G)
4. **Loop 3:** Новые описания (J) — поиск у конкурентов через Playwright
5. **Loop 4:** Добавить инструкцию в описание (J) — поиск на pyyplbot.com
6. **Loop 5:** Главная картинка (AI-генерация карты + Pillow текст)
7. **Loop 6:** Шаблонные картинки (Pillow, готовый фон + текст)

### Цепочка Б — игры/DLC
- Полностью отдельная цепочка со своими промптами
- Обработка по одному товару
- Свои правила для описаний (ключ активации ≠ подарок Steam)

### Группировка
- DLC и сами игры — без группы, по одному
- Пополнение счёта игры (PUBG UC, Valorant VP) — группа по номиналам/странам
- Loop 0 перепроверяет правильность всех групп (скрипт мог ошибиться)

### Описания
- Переписываем ВСЕ 3334, не только пустые
- Не теряем ключевую информацию о товаре
- Источник для нового описания: старое название + старое описание + конкуренты
- Не копируем конкурентов — переписываем своими словами
- Смысл товара не меняется (номинал, регион, валюта остаются)

### Конкуренты (источники референсов)
- **pyyplbot.com/gift-cards/** — основной сайт
- **Витрина ПиплБот на Маркете** (business ID 84407134)
- **Поиск по всему Маркету** — если на pyyplbot нет нужного товара
- Приоритет: карточки с продажами
- Для игр: НЕ путать "подарок Steam" с "ключ активации"

### Картинки (8 штук на товар)
1. **Главная** — AI-генерация карты + Pillow (название, номинал, флаг, регион)
2. **"Моментальная доставка"** — шаблон Pillow, одинаковая для всех
3. **Инструкция способ 1** — шаблон Pillow, зависит от бренда
4. **Инструкция способ 2** — шаблон Pillow, зависит от бренда
5. **Инструкция способ 3** — шаблон Pillow, если есть
6. **"Ваше мнение важно"** — шаблон Pillow, одинаковая для всех
7. **"Вид письма"** — скриншот email + рамка
8. **"Поможем 24/7"** — шаблон Pillow, одинаковая для всех

- Фон единый (стиль магазина, светлый с иконками)
- AI-генерация только для изображения карты в центре главной картинки
- Pillow для всего текста, плашек, иконок
- Формат: 3:4 (1080x1440)
- API для AI-генерации — подберём экспериментально, есть референсы

### Оптимизация токенов
- CSV вместо xlsx (Claude читает напрямую через Read с offset/limit)
- Несколько маленьких csv вместо одного большого
- Промпты на английском (~2x экономия)
- Жёсткий список файлов в промпте (не лазить по проекту)
- Подписка Max $200/мес — считаем расход после тестового прогона
