# Задача: Разработка дизайна карточек товаров для Яндекс Маркета

## Контекст

Мы продаём цифровые товары (подарочные карты, ваучеры, пополнения, подписки) на Яндекс Маркете. Нужно создать систему генерации изображений для карточек товаров. Всего ~3300 товаров, для каждого нужно 8 картинок.

Итоговая цель — Python-скрипт(ы) на Pillow, которые принимают данные товара (бренд, номинал, валюта, регион, инструкция активации) и генерируют 8 готовых PNG.

## Технические требования Яндекс Маркета

- Формат: **3:4** (1080x1440 px)
- Минимум: 300x300, максимум: 10 МБ
- Форматы: JPG, PNG
- Товар должен занимать не менее 75% кадра
- **Запрещено:** водяные знаки маркетплейсов, ценники, скидки, "хит", "лучший", контакты, ссылки, размытые фото

## 8 картинок на товар

### Картинка 1 — Главная (уникальная для каждого товара)
- **Центр:** изображение карты/ваучера в фирменных цветах бренда (AI-генерация, вставляется в шаблон)
- **Сверху:** заголовок (тип товара + бренд), например "КАРТА ПОПОЛНЕНИЯ XBOX"
- **Плашка:** флаг страны + номинал (например 🇺🇸 $10)
- **Снизу:** текст региона ("Подходит для аккаунтов США") + логотип магазина
- **Фон:** единый стиль магазина (светлый, с полупрозрачными тематическими иконками — геймпады, клавиатуры, мышки, наушники)

### Картинка 2 — "Моментальная доставка" (одинаковая для всех товаров)
- Тот же фон
- Заголовок: "МОМЕНТАЛЬНАЯ ДОСТАВКА"
- Крупный текст: "Мгновенный доступ. Получите ваш товар за считанные секунды"
- Внизу: текст региона + логотип магазина

### Картинки 3, 4, 5 — Инструкции по активации (зависят от бренда)
- Тот же фон
- Заголовок: "ИНСТРУКЦИЯ ПО АКТИВАЦИИ НА [ПЛАТФОРМА]"
- Пошаговый текст (3-4 шага)
- Внизу: текст региона + логотип магазина
- У каждого бренда может быть 1-3 способа активации (консоль, сайт, приложение)

### Картинка 6 — "Ваше мнение важно" (одинаковая для всех)
- Тот же фон
- Заголовок: "Ваше мнение важно"
- Текст с просьбой написать в поддержку перед отзывом
- Логотип магазина

### Картинка 7 — "Вид письма для подтверждения" (одинаковая для всех)
- Тот же фон
- Заголовок: "ВИД ПИСЬМА ДЛЯ ПОДТВЕРЖДЕНИЯ:"
- Скриншот/макет email от Яндекс Маркета с активацией цифрового товара
- Внизу: текст региона + флаг

### Картинка 8 — "Поможем 24/7" (одинаковая для всех)
- Тот же фон
- Заголовок: "ПОМОЖЕМ 24/7"
- Текст: "Круглосуточная помощь по любым вопросам"
- Логотип магазина

## Инструменты

- **Pillow (PIL)** — основной инструмент для всех картинок: фон, текст, плашки, иконки, наложение элементов
- Pillow умеет: шрифты TTF/OTF любого размера, тени (смещённый текст + blur), обводка, градиенты, наложение PNG с прозрачностью, скруглённые прямоугольники
- **AI API** — только для генерации изображения карты в центре картинки 1 (подберём позже, пока делаем шаблон с placeholder)
